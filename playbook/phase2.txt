  Q: What format will the returned data take?
  -> Array at root: [...]
    parse directly: JSON.parse(response.body)
  -> Wrapped in key: { "users": [...] }
    parse then dig: JSON.parse(response.body)["users"]
  -> Single object: { "id": 1, "name": "..." }
    parse directly: JSON.parse(response.body)
