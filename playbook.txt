  SCOPE
  Q: "Are we building the full CRUD or just a read/display feature?"
  -> READ ALL ONLY: Simplest option if only one action needed
      get "/users", to: "users#index"
  -> READ AND SHOW: Only need index and show routes
    resources :users, only: [:index, :show]
    → GET /users       → UsersController#index
    → GET /users/:id   → UsersController#show
  -> READ AND CREATE: index, show, new and create needed
    resources :users, only: [:index, :show, :new, :create]
    → GET  /users        → index
    → GET  /users/:id    → show
    → GET  /users/new    → new (form)
    → POST /users        → create (submit form)
  -> FUL CRUD:
    resources :users
    → GET    /users          → index
    → GET    /users/:id      → show
    → GET    /users/new      → new
    → POST   /users          → create
    → GET    /users/:id/edit → edit
    → PATCH  /users/:id      → update
    → DELETE /users/:id      → destroy
